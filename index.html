HTML Input Master Reference

The <input> element is the foundational bridge between user intent and data processing. Mastering its various types is essential for building accessible, high-converting web applications.

Text Input

The standard single-line text field used for basic alphanumeric data.

Value: None
<input type="text">

Password

Obscures input characters for sensitive information security.

<input type="password">

Color Picker

Allows users to select a color via the system's native interface.

HEX: #6366f1
<input type="color">

Range Slider

Selects a numeric value from a slider within a specified interval.

Intensity: 50%
<input type="range">

Date Selector

Triggers a native calendar picker for day/month/year selection.

Selected: YYYY-MM-DD
<input type="date">

Number

Restricts input to numeric values; supports min, max, and steps.

<input type="number">

File Upload

Allows users to select one or more files from their storage.

No file chosen
<input type="file">

Checkbox

Toggle states or select multiple options from a set.

Status: Unchecked
<input type="checkbox">
